## 2. 您「用直线拟合找离群再手删」的学理化表述

实际做法可写为**可发表的统计语言**（与「笨拙」等价但更规范）：

- 在**某一响应**（如拉伸强度或伸长率）与**少量解释变量**（甚至单一结构描述量）之间建立**普通最小二乘线性模型** \(\,y = \mathbf{x}^\top\boldsymbol{\beta} + \varepsilon\,\)。  
- 计算**标准化残差**（studentized residuals）\(r_i^*\)，其在线性、正态、同方差假定下近似服从 \(t\) 分布；**绝对值过大**的样本对应「在简单线性结构下不可兼得的观测」，可视作**候选离群点**。  
- **人工复核**后删除，等价于采用**基于残差的显式阈值**（例如 \(|r_i^*| > t_{1-\alpha/2,\,n-p-1}\)，或对多重比较做 Bonferroni 校正），只是阈值未在初稿中公式化。

**与多元机器学习的衔接**：单响应线性残差法**未利用特征空间的联合分布**；而后续建模使用**多维特征**，更匹配的多元离群判据是下节的**马氏距离**（或稳健协方差下的稳健马氏距离）。

## 3. 推荐在文中采用的「正式算法」表述：特征空间马氏距离 + \(\chi^2\) 阈值

若希望与「多维特征 + 非线性模型」一致、且便于审稿人接受，建议在方法学中**明确写清**下列流程（若历史上以手删为主，可写「与下述规则等价地整理了数据集」或「修订稿中按下述程序复算并固定名单」）：

1. **对象**：仅对**特征矩阵** \(\mathbf{X} \in \mathbb{R}^{n \times p}\)（如组成/拓扑/工艺编码列，**不含**力学或愈合响应）作检测。  
2. **预处理**：各列**标准化**（零均值、单位方差），避免量纲支配距离。  
3. **马氏距离**：\(d_i^2 = (\mathbf{x}_i - \hat{\boldsymbol{\mu}})^\top \hat{\mathbf{\Sigma}}^{-1} (\mathbf{x}_i - \hat{\boldsymbol{\mu}})\)。  
4. **零假设下的参照分布**：在多元正态近似下，\(d_i^2 \sim \chi^2_p\)。取临界值 \(\chi^2_{p,\,1-\alpha}\)（常用 \(\alpha = 0.05\)），**超过临界值**的配方判为特征空间中的**高杠杆/异常点**并剔除。  
5. **小样本注意**：\(n\) 不大时 \(\hat{\mathbf{\Sigma}}\) 不稳定，可改用 **Ledoit–Wolf 收缩协方差**、**最小协方差行列式（MCD）稳健估计**、或对协方差加**岭项**后再求逆，并在正文或附录**一句话交代**。

**复现与对照**：同目录 [`mahalanobis_feature_outliers.py`](mahalanobis_feature_outliers.py) 在 `Final_Features_Ultimate.csv` 上按固定特征列、z-score、岭协方差与 \(\chi^2_{p,\,0.95}\)（Wilson–Hilferty 近似）计算 \(d^2\)；`--write-appendix` 可生成 [`附录A_马氏距离特征空间离群筛查.md`](附录A_马氏距离特征空间离群筛查.md)，其中含**算法标记名单与人工定稿 8 条剔除的交集/差集**（二者不必完全一致，须在正文诚实说明）。

**诚信表述**：若最终入表名单与「严格按上述程序一次性跑代码」尚未逐条对齐，可写：*初步筛选结合简单线性模型的残差检查与领域知识；特征空间离群按马氏距离与 \(\chi^2\) 阈值复核（附录 A 给出程序、阈值与名单对照）。*

## 4. 集合 A（力学）与集合 B（愈合）

以当前 `Final_Features_Ultimate_all_deletion.csv`（**84** 行）为准：

- **力学建模（集合 A）**：本表中 **84** 条均同时具有可用的 `tensile_strength` 与 `elongation`（已排除 `PBA-PU-3` 等无可靠力学记录者）。若单目标建模可另报 \(n\)。  

- **愈合效率（集合 B）**：在 **84** 条母体上，对 `healing_eff` 采用 **列表删除（listwise deletion / complete-case analysis）**：**仅当文献或实验中报告了愈合效率数值**时该字段非空；**当前非空为 37 条**、**空值 47 条**。  
  - **与离群剔除的区分（可放脚注）**：这 47 条**不是**因马氏距离或残差阈值从特征空间删除，而是**原始数据中未测定或未报道愈合效率**，故愈合子模型样本量小于力学模型；**未对愈合结局再做统计离群剔除**（若另有剔除需单独说明）。

## 5. 可直接放入中文论文的「数据预处理」段落（示例稿，仅 92 → 84）

> 以配方级特征表为起点，共 **92** 个聚氨酯配方样本。  
> **第一步（力学可用性）**：剔除拉伸强度或伸长率缺失、或测试明显无效的记录（本数据集中对应 **1** 条：`PBA-PU-3`）。  
> **第二步（离群与异常）**：在力学响应与结构/组成相关变量之间建立**普通最小二乘**关系，计算**标准化残差**，将残差极端者标为候选离群点；并结合配方类型与文献可重复性做**人工复核**。另对**非典型体系**（如标注为无软段凝胶等）予以领域排除。上述步骤合计再剔除 **7** 条，使样本量由 92 减至 **84**。  
> **第三步（与多维建模一致的特征空间复核）**：在**不含力学与愈合结局**的数值特征上作列标准化，计算**马氏距离**，并以 \(\chi^2_{p,\,0.95}\)（\(\alpha=0.05\)）为参照识别高杠杆点；小样本下协方差采用**岭正则**等稳定化估计（程序与算法标记名单见附录 A）。**定稿 84 条以第二步复核后的名单为准**；附录中马氏距离结果可与该名单交叉对照。  
>  
> **愈合效率（集合 B）**：在已定稿的 **84** 条上，仅保留文献或实验中**报告了愈合效率**的样本（**列表删除，complete-case**），得 **n = 37**；其余 **47** 条为结局缺失，**并非**再经离群算法删除。

（期刊若限幅，可删去第三步整句，仅保留「OLS 残差 + 领域复核」；剔除的 8 个 `sample_id` 见上文 §1b。）
