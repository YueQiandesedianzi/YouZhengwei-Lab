# 不纳入说明（精简原则）

本传承包刻意剔除以下内容，避免噪音干扰后续使用。

## 一律不纳入

| 类别 | 原位置示例 | 原因 |
|---|---|---|
| 图片 / PPT / 备选图 | `文章绘图/`、`outline备选/`、`*.png` | 用户要求只要代码与数据 |
| 虚拟环境 | `.venv_figs/` | 体积大且不可移植 |
| 调试与备份表 | `*backup*`、`*debug*`、多次 drop log | 非定稿口径 |
| 拉力机原始曲线 | `小论文/论文数据/**` | 非建模输入；实验汇总已在论文中 |
| Notebook 大文件 | `*.ipynb`（数 MB～数十 MB） | 逻辑已由 `.py` / 结果表承接 |
| 探索分支 `多文献课题_new` | route38 / 409 样本线 | 与终稿 314 口径不一致 |
| Task06 二阶段对照 | `06_二阶段降维消融/` | 终稿不以 old33/stage2 为选择依据 |
| 过程长日志 | `STAR_执行过程记录.md`、PPT outline | 信息已压缩进本包文档 |
| 出图样式代码 | `plot_style_rules.py`、`文章绘图/*.py` | 无图需求 |
